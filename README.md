# self-introduction-practice

## 概要

COACHTECHのハンズオン教材で作成した、自己紹介ページです。出身地や趣味、問い合わせフォームなどの項目を有する自己紹介ページです。

## 使用技術

- HTML5

## 学んだこと

- HTMLでブラウザ画面に実際に表示されるテキストを書く位置など、実践すると理解しやすいこと
- labelで紐づけるにあたり、各項目を整理しながら、順序立てて作業を進める必要性
- Tabキーを活用すると、かなり作業の時間短縮になること

## 動作確認

リンクをクリックし、意図通り新しいタブで開くかを確認した。また、送信時に必須項目となる名前の欄や、問い合わせ内容を入れずに送信するとエラーになるかを確認した。問い合わせの種別を選択することができるか、カーソルを動かすことで確認した。また、問い合わせフォームに、数行テキストを打ち込むことで、1行に入力が制限されないことを確認した。
